# Netflix Data Analysis using Tableau

## 📌 Project Overview

This project focuses on analyzing Netflix’s content library using **Tableau** to uncover insights related to content distribution, genres, countries, release trends, and ratings. The goal of this project is to demonstrate **business analysis and data visualization skills** by converting raw data into meaningful, decision‑ready dashboards.

This project is designed to be **beginner‑friendly** and suitable for **Business Analyst / Data Analyst entry‑level roles**.

---

## 🎯 Objectives

* Understand Netflix content trends across years
* Analyze distribution of Movies vs TV Shows
* Identify top genres and countries producing content
* Explore rating patterns and content duration
* Practice storytelling using Tableau dashboards

---

## 📂 Dataset

* **Source:** Public Netflix dataset (CSV format)
* **Records:** Movies and TV shows available on Netflix
* **Key Fields:**

  * Title
  * Type (Movie / TV Show)
  * Genre
  * Country
  * Release Year
  * Rating
  * Duration

> Note: The dataset was cleaned and pre‑processed before visualization.

---

## 🧹 Data Cleaning & Preparation

The following steps were performed before building dashboards:

* Removed duplicate records
* Handled missing values (Unknown / Not Available)
* Split multi‑value columns (Genres, Countries)
* Standardized date and duration formats
* Created calculated fields for analysis

---

## 📊 Dashboards & Insights

### 1️⃣ Content Distribution Dashboard

* Movies vs TV Shows comparison
* Year‑wise content growth
* Key insight: Netflix has rapidly increased content after 2015, with Movies dominating the catalog

### 2️⃣ Genre Analysis Dashboard

* Top genres by content count
* Genre popularity across years
* Insight: Drama and International content dominate Netflix’s library

### 3️⃣ Country‑Wise Analysis Dashboard

* Content distribution by country
* Top producing countries
* Insight: The United States leads, followed by India and the UK

### 4️⃣ Ratings & Duration Dashboard

* Distribution of ratings
* Movie duration and TV show seasons analysis
* Insight: TV‑MA and TV‑14 are the most common ratings

---

## 🛠 Tools & Technologies Used

## 📈 Key Business Takeaways

* Content strategy shifted significantly after 2015
* Netflix focuses heavily on international and drama content
* Ratings indicate strong targeting of mature audiences
* Country‑specific insights can guide regional content investments
